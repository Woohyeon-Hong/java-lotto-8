# java-lotto-precourse

## **🎯 기능 목록**

### 1. 로또를 구매한다.

---

- [x]  로또 구입 금액을 입력 받는다.
    - [x]  `IllegalArgumentException` : 자연수가 아닌 경우
    - [x]  `IllegalArgumentException` : 1000의 배수가 아닌 경우
- [x]  발행 할 로또 수량을 계산하고 출력한다.
    - [x]  구입 금액을 1,000으로 나누어 로또 개수를 계산한다.
    - [x]  계산된 로또 수량을 출력한다.
- [x]  로또를 발행한다.
    - [x]  1부터 45 사이의 **중복되지 않는 6개의 숫자**를 생성한다.
    - [x]  생성된 로또 번호를 출력한다.
    - [x]  생성된 로또 번호를 저장한다.
    - [x]  발행해야 하는 모든 로또에 대해 위 과정을 반복한다.

### 2. 로또를 추첨한다.

---

- [x]  당첨 번호를 입력받는다.
    - [x]  `IllegalArgumentException` : 자연수나 쉼표가 아닌 값이 입력된 경우
    - [x]  `IllegalArgumentException`: 숫자가 6개가 아닌 경우
    - [x]  `IllegalArgumentException` : 숫자가 1 ~ 45 사이의 값이 아닌 경우
    - [x]  `IllegalArgumentException` : 숫자가 서로 중복되는 경우
- [x]  보너스 번호를 입력받는다.
    - [x]  `IllegalArgumentException` : 자연수가 아닌 경우
    - [x]  `IllegalArgumentException` : 숫자가 1 ~ 45 사이의 값이 아닌 경우
    - [x]  `IllegalArgumentException` : 당첨 번호와 중복되는 경우
- [x]  당첨 결과를 판정한다.
    - [x]  발행된 각 로또 번호를 당첨 번호 및 보너스 번호와 비교한다.
    - [x]  일치하는 숫자의 개수를 계산한다.
    - [x]  일치 개수 및 보너스 일치 여부에 따라 당첨 등수를 결정한다.
    - [x]  등수별 당첨 횟수를 누적하여 통계 데이터를 업데이트한다.

### 3. 당첨 내역을 보여준다.

---

- [x]  당첨 내역을 정렬한다.
    - [x]  당첨된 개수(=등수별 당첨 횟수)가 많은 순으로 정렬한다.
    - [x]  동일한 당첨 개수 내에서는 일치 개수(=등수)에 따라 오름차순으로 정렬한다.
- [x]  로또 당첨 통계를 출력한다.
    - [x]  당첨 통계 문구를 출력한다.
    - [x]  등수별 당첨 횟수를 출력한다.
